# AI Smart Car using Raspberry Pi

## Overview
This project is an AI-based smart car developed using Raspberry Pi.  
The car can be controlled using multiple methods such as gesture control, voice commands, and remote control. The project combines embedded systems, computer vision, and automation technologies to create an intelligent robotic vehicle.

---

## Features
- Gesture control using OpenCV
- Voice-controlled movement
- Wireless remote control
- Real-time camera processing
- Obstacle detection
- Smart movement control

---

## Technologies Used
- Raspberry Pi
- Python
- OpenCV
- Wi-Fi Communication

---

## Hardware Components
- Raspberry Pi Board
- DC Motors
- Motor Driver
- Camera Module
- Ultrasonic Sensor
- Battery Pack
- Chassis

---

## Software Requirements
- Python 3
- OpenCV
- Raspberry Pi OS
- Arduino IDE




## Future Improvements
- AI-based autonomous navigation

## Conclusion
This project demonstrates the integration of AI, embedded systems, and computer vision to build a smart robotic vehicle capable of intelligent control and automation.
